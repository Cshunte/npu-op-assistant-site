NPU 算子开发助手

一个面向 NPU 算子开发的问答与文档检索工具。把算子文档、部署经验和可执行工具接到一起，用对话的方式查资料、答问题。

在线体验

它能做什么

  • 算子文档问答：按 ## 标题切片建索引，检索相关段落再交给模型作答。
  • 三种模型模式：offline（免配置演示）、api（OpenAI 兼容接口）、vllm（本地部署模型），统一一套调用方式。
  • 工具调用：内置 3 个可执行函数，Agent 会按需调用并控制最多 3 轮，避免无限循环。
  • 两种后端入口：standalone.py 只用标准库、零依赖可跑；main.py 是 FastAPI 版，方便接生产服务。

整体结构

技术栈

前端原生 HTML / CSS / JavaScript，无构建步骤，直接打开即用。
后端Python 标准库 HTTP（零依赖）与 FastAPI 双入口。
检索文档按标题切片 + 关键词重合度打分，带相关性门槛。
模型OpenAI 兼容接口，离线 / API / vLLM 三种模式可切换。

一个实际修掉的问题

早期版本里，问「你能做什么」会把 Resize 等算子文档原样倒出来，属于典型的答非所问。排查下来是三个原因叠在一起：

  1. 没有意图识别，元问题（问能力、问用法）也被当成知识检索；
  2. 检索没有相关性门槛，任何问题都会返回得分最高的文档；
  3. 离线回答是把检索片段无脑拼接，没有组织。

对应做了三处修改：加元问题关键词识别、给检索加最小匹配数门槛、重写离线回答逻辑。这个问题后来整理成了一份 STAR 结构的复盘文档，放在项目仓库里。

在线演示跑的是 offline 模式：RAG、工具调用和意图识别都在，模型回答是内置演示逻辑。想接真实模型，配置 API Key 或 vLLM 地址切换模式即可。
